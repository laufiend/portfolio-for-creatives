# Random Image Swap on Hover

A Pen created on CodePen.

Original URL: [https://codepen.io/editor/laufiend/pen/019fdf0c-99d4-70d6-a61a-18d802a7164b](https://codepen.io/editor/laufiend/pen/019fdf0c-99d4-70d6-a61a-18d802a7164b).

A simple jQuery demo that randomly changes an image when you hover over it. The new image remains in place after the mouse leaves, and hovering again selects a different image.

This demo uses three Western-themed SVG icons—boots.svg, western.svg, and wheel.svg—as the hover images, with beer.svg as the default image.

Uses: HTML, CSS, jQuery, SVG
